# Лендинг мастерской вывесок (Санкт-Петербург)

Чистый HTML/CSS/JS, без сборки и зависимостей. Готов к заливке на Timeweb как есть.

## Файлы

```
index.html      — лендинг
privacy.html    — политика обработки персданных (ШАБЛОН, проверить у юриста)
styles.css      — все стили
script.js       — форма расчёта + мобильное меню
images/         — 6 заглушек работ (SVG)
robots.txt, sitemap.xml
analiz-konkurentov.md — исследование рынка, на котором построен лендинг
```

## Что доделать

1. **Отправка формы.** В `script.js` отправка имитируется. Раскомментировать блок `fetch` и положить рядом `send.php` (или подключить форм-сервис).
2. **Фото работ.** Заменить `images/work-*.svg` на реальные снимки: ширина ~1600 px, WebP или JPEG до 200 КБ, `src` и `alt` обновить под то, что на фото.
3. **Favicon.** Сейчас его нет.
4. **Политика.** `privacy.html` — рабочий шаблон, реквизиты подставить, текст показать юристу.
5. **Проверить суммы штрафов** по 168-ФЗ перед публикацией: в текстах они указаны со слов вторичных источников.

## Дизайн-система

```
Фон        #F7F4EF     Текст        #22201C
Карточки   #FFFFFF     Приглушённый #6B655C
Акцент     #D94E1F     Линии        #E4DED2
Графит     #2B2E33     Свечение     #F0B429
```

Заголовки — Oswald, текст — PT Sans (Google Fonts). Радиус 4 px, теней почти нет.
Заглавные буквы применяются только там, где так делают настоящие вывески: логотип и макеты вывесок.

## Типографика

Короткие предлоги, союзы, числа с единицами и тире связаны через `&nbsp;` — висячих предлогов нет ни на десктопе, ни на мобильном. При правке текстов это правило нужно поддерживать.
