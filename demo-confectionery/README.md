# Вензель — демо-лендинг кондитерской

Демо-проект для портфолио. Вымышленная кондитерская «Вензель» (Москва), торты на заказ. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Файлы
- `index.html` — разметка и весь контент
- `styles.css` — стили (светлая тёплая тема, ягодный акцент, адаптив)
- `script.js` — меню, счётчики, FAQ, маска телефона, отправка формы

## Как открыть
Откройте `index.html` в браузере. Сборка не нужна.

## Деплой на Timeweb
Залейте три файла (`index.html`, `styles.css`, `script.js`) в корень сайта. Точка входа — `index.html`.

## Что заменить перед сдачей реальному клиенту
1. **Фото.** Стоковые кадры с Pexels (тематические, без водяных знаков) — видно по ссылкам `images.pexels.com` в `index.html`. Замените на реальные фото тортов кондитерской: hero, каталог, фото кондитера, галерею работ.
2. **Контент — вымышленный.** Название «Вензель», адрес (Пятницкая, 25), телефон, отзывы, имя кондитера (Полина Астахова), цифры (10 лет, 12 000 тортов, рейтинг 4,9) — всё демо. Заменить на настоящие данные.
3. **Форма заказа.** Заявка не уходит на сервер, только показывается сообщение об успехе (см. комментарий в `script.js`). Подключите бэкенд, CRM кондитерской или отправку заявки в Telegram-бот.
4. **Каталог и цены.** Позиции и цены («от X ₽/кг») — примерные. Обновите под реальный ассортимент.
5. **Ссылки соцсетей** в футере (Telegram, WhatsApp, ВКонтакте) — проставить настоящие.

## Технические детали
- Адаптив: брейкпоинты 1024 / 900 / 560 px.
- Анимации появления через IntersectionObserver, уважают `prefers-reduced-motion`.
- Шрифты Cormorant Garamond (заголовки) + Manrope (текст) через Google Fonts.
- Светлая тема залочена (брендовое решение под кондитерскую).
- Формы скруглений: кнопки — pill, карточки/фото — 16px, поля — 10px.
