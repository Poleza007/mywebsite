# Портфолио — Камиль Тапаев

Сайт-портфолио веб-разработчика (сайты и чат-боты для малого бизнеса). Чистый HTML/CSS/JS, без сборки и зависимостей. Ссылается на два демо-проекта.

## Файлы
- `index.html` — разметка и весь контент
- `styles.css` — стили (тёмный минимализм, плёночный grain, шартрёз-акцент)
- `script.js` — меню, reveal, FAQ, отправка формы
- `demo-barbershop/` — демо-лендинг барбершопа (отдельный сайт)
- `demo-confectionery/` — демо-лендинг кондитерской (отдельный сайт)

## Как открыть
Откройте `index.html` в браузере. Сборка не нужна. Ссылки «Работы» ведут на демо в подпапках.

## Деплой на Timeweb
Вариант 1 (всё вместе): залейте корень `mywebsite/` целиком — портфолио в корне, демо в подпапках, относительные ссылки работают как есть.
Вариант 2 (демо на отдельных доменах): залейте портфолио отдельно, а в `index.html` замените ссылки `demo-barbershop/index.html` и `demo-confectionery/index.html` на реальные URL демо (в блоке «Работы» и в футере).

## Что заменить/дополнить
1. **Фото.** В блоке «Обо мне» стоит плейсхолдер «Фото» (пунктирная рамка). Замените на реальное фото Камиля, `.about__photo` в разметке. Живое фото сильно повышает доверие.
2. **Форма.** Заявка не уходит на сервер, только показывается сообщение об успехе (см. комментарий в `script.js`). Подключите отправку в Telegram-бот, на почту или сервис форм.
3. **Отзывы.** Раздела отзывов намеренно нет (реальных клиентов пока нет, фейковые отзывы подорвали бы доверие). По мере появления клиентов добавьте блок «Отзывы» с реальными цитатами (структуру можно взять из демо).
4. **Контакты.** Telegram `@Wayzamanho` и WhatsApp `+7 928 596-63-48` проставлены. При необходимости добавьте телефон/почту для показа.

## Технические детали
- Адаптив: брейкпоинты 1024 / 900 / 560 px.
- Анимации появления через IntersectionObserver, уважают `prefers-reduced-motion`.
- Шрифты Space Grotesk (заголовки) + Manrope (текст) через Google Fonts.
- Тёмная тема залочена. Плёночный grain: фиксированный оверлей `body::after` (SVG feTurbulence, opacity 0.07, pointer-events none), не мешает кликам и не грузит скролл.
- Один акцент: приглушённый шартрёз `#c7d34f`. Скругления: кнопки — pill, карточки/поля — 14px.
