# КРОМКА — демо-лендинг барбершопа

Демо-проект для портфолио. Вымышленный барбершоп «КРОМКА» (Москва). Чистый HTML/CSS/JS, без сборки и зависимостей.

## Файлы
- `index.html` — разметка и весь контент
- `styles.css` — стили (тёмная тема, золотой акцент, адаптив)
- `script.js` — меню, счётчики, FAQ, маска телефона, отправка формы, рендер цен
- `data/prices.js` — цены услуг (редактируемые данные)

## Как открыть
Просто откройте `index.html` в браузере. Сборка не нужна.

## Деплой на Timeweb
Залейте файлы (`index.html`, `styles.css`, `script.js`, папку `data/`) в корень сайта. Точка входа — `index.html`.

## Редактирование цен (клиент меняет сам)
Блок «Услуги и цены» больше не «зашит» в HTML — он рисуется из данных. Есть два режима.

### Режим 1 (по умолчанию): файл `data/prices.js`
Цены лежат в `data/prices.js`. Чтобы поменять — правите значение в кавычках и сохраняете файл. Подходит, если правки вносите вы.

### Режим 2: Google-таблица (клиент правит сам, без вашего участия)
Позволяет клиенту менять цены прямо в Google-таблице, ничего не зная про код. Настройка:
1. Создайте Google-таблицу с колонками (по порядку): **Услуга · Описание · Время · Цена**. Первую строку-заголовок можно оставить, скрипт берёт строки с данными.
2. `Файл → Поделиться → Опубликовать в интернете` (Publish to web). Так таблица становится доступной только для чтения.
3. Скопируйте **ID таблицы** из её адреса: `docs.google.com/spreadsheets/d/`**`ЭТОТ_ID`**`/edit`.
4. В `script.js` впишите его в `var SHEET_ID = '...'`. Номер листа задаётся в `SHEET_GID` (у первого листа это `0`, у следующих — число после `gid=` в адресе таблицы).
5. Готово: сайт берёт цены из таблицы. Клиент меняет ячейку → после обновления страницы цена меняется на сайте. Если таблица недоступна, сайт автоматически покажет цены из `data/prices.js` (резерв).

> Важно: никакого логина и пароля на самом сайте нет. «Вход» для редактирования — это аккаунт Google клиента (таблицу правит он у себя). Публичный сайт только читает данные, ломать на нём нечего.

## Что заменить перед сдачей реальному клиенту
1. **Фото.** Сейчас стоят стоковые кадры с Pexels (тематические, без водяных знаков) — их видно по ссылкам `images.pexels.com` в `index.html`. Замените на реальные фото барбершопа: hero, интерьер, портреты барберов, лукбук работ, фасад.
2. **Контент — вымышленный.** Название, адрес (Чистопрудный бул., 12), телефон, отзывы, имена барберов, цифры статистики (11 лет, 180 000+ стрижек, рейтинг 4,9) — всё демо. Заменить на настоящие данные.
3. **Форма записи.** Сейчас заявка не уходит на сервер, только показывается сообщение об успехе (см. комментарий в `script.js`). Подключите одно из:
   - виджет/API YClients,
   - отправку заявки в Telegram-бот,
   - свой бэкенд или сервис форм.
4. **Карта.** В блоке «Контакты» вместо фото фасада можно встроить интерактивную Яндекс.Карту (iframe с реальными координатами).
5. **Ссылки соцсетей** в футере (Telegram, WhatsApp, ВКонтакте) — проставить настоящие.

## Технические детали
- Адаптив: брейкпоинты 1024 / 900 / 560 px.
- Анимации появления через IntersectionObserver, уважают `prefers-reduced-motion`.
- Шрифты Oswald + Manrope подключены через Google Fonts.
- Тёмная тема залочена (брендовое решение под барбершоп).
